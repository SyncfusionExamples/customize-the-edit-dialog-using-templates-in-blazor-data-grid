# Customize the Edit Dialog Using Templates in Blazor Data Grid

A quick-start project that helps you to customize the edit dialog in Syncfusion [Blazor Data Grid](https://www.syncfusion.com/blazor-components/blazor-datagrid). This project contains simple code customizations to add custom components like Numeric TextBox, AutoComplete, DatePicker, Dropdown List, and TextBox to the edit dialog using a template.

## Features

* Fast rendering with virtualization and row/column virtualization
* Sorting, filtering, grouping, and searching capabilities
* Inline, batch, and dialog editing modes
* Template columns, column resizing, reordering, and freezing
* Excel and PDF export (requires additional Syncfusion export packages)

## Prerequisites

* Visual Studio 2022 or later
* Visual Studio Code

## How to run the project

1. Clone or download this repository to a location in your system.
2. Open the solution file using the Visual Studio or Visual Studio code.
3. Restore the NuGet packages by rebuilding the solution or run `dotnet restore`.
4. Build the project to ensure there are no compilation errors.
5. Run the project.

Optional CLI Commands:

```powershell
dotnet restore
dotnet build
```
